# Local asset provenance

- earth-day.webp: Albedo.jpeg from user-supplied models/earth (2).zip, resized to 2048×1024 and encoded as WebP.
- earth-clouds.webp: Clouds.png from the same user-supplied archive, resized to 2048×1024 and encoded as WebP.
- earth-poster.png: browser capture of the actual Three.js Earth scene implemented in src/scenes.js. No generative image model was used.
- icons.woff: selected glyph subset of Phosphor Regular from @phosphor-icons/web 2.1.2. The package MIT license is included as phosphor-license.txt.

The source Earth archive did not provide an author/license file at its top level. These assets are retained as user-provided project materials; no new authorship or licensing claim is made.
