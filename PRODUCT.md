# OceanEmbed
<!-- impeccable:product-schema 1 -->

## Platform
web

## Purpose and users
OceanEmbed proposes daily reconstruction of subsurface ocean temperature from satellite observations for the North Indian Ocean. The public landing page introduces the concept to SIH judges, scientists, and visitors, and leads to ocean exploration and architecture information.

## Current scope
Exactly three landing-page sections: Earth hero, dashboard CTA, architecture CTA. Dashboard and architecture buttons open functional, clearly labelled previews. A production dashboard and trained inference backend are future work.

## Brand commitments
The user explicitly requests pure #000000 backgrounds, white text, a clean minimalist visual identity, an Earth hero with optional satellite, and smooth purposeful animation. Use the existing Three.js, GSAP and Lenis dependencies.

## Evidence
Product requirements: problem_statement.md. Proposed scientific implementation: architecture_design_v3_final.md. Original broader website brief: Brief.md. The latest user request narrows that brief to the three-section landing page. Local Earth textures come from the user-supplied models/earth (2).zip. No trained model outputs or observed profiles have been provided.

## Data integrity
The landing-page depth volume and modal profiles are explicitly illustrative. Architecture descriptions are proposed system design. Do not imply measured model performance, INCOIS endorsement, or operational data availability.
